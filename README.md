# Практика: мультимедийный сайт

## Запуск
1. Перейти в свою папку на сервере.
2. npm install
3. npm run dev   ← запускает сборку и следит за файлами

## Где что писать
- Разметка: index.html, about.html, work.html (в корне)
- Стили: src/scss/*.scss
- Картинки/видео: src/img/ (в корне img/ — НЕ трогать)
- Скрипты: src/js/main.js

## Как проверить
Открыть адрес своего слота в браузере, после изменений — Ctrl+F5.

## Этапы
1. HTML + SCSS + Gulp (недели 1–2) — обязателен
2. PHP + MySQL (неделя 3) — если этап 1 принят
3. Админка и загрузка файлов (неделя 4) — если этап 2 принят

Каждый этап = один коммит в Git.
